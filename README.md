# othello-ai
Othello game-playing AI using Negamax search, alpha-beta pruning, and heuristic evaluation

Features
- Negamax search with alpha-beta pruning
- Adaptive search depth based on game state
- Heuristic board evaluation using positional weights, mobility, corner control, and piece stability
- Move ordering to improve search efficiency
- Random-move baseline for comparison

Technologies
- Python
- Adversarial search algorithms
- Heuristic evaluation
